使用指南

快速掌握 TeamFlow Wiki 的核心协作工作流：

1

模块化块级编辑

点击任意文本块即可直接编辑，按 Enter 键换行。每一行都是独立积木，可自由修改。

2

斜杠命令 (Slash Command)

在新行输入 / 即可呼出快捷菜单，一键插入标题、分隔线、图片或普通段落。

3

拖拽手柄排序

悬停于每一行左侧可显现 ⠿ 手柄，长按即可上下拖拽块重新排布内容顺序。

4

GitHub 自动云同步

在设置 (⚙️) 中输入 GitHub Token 及仓库信息后，即可免安装 Git，一键向远端推送更新。
