📝 关于我 / About Me

我是Hkz，Team Homework Blog (团队作业的博客) 协作展示门户的主创与全栈开发者。我喜欢折腾各类前端框架和硬件集成，本项目是我基于原生前端技术栈（Vanilla JS, ES Modules, CSS Variables）开发的一个无编译、免安装协作系统，旨在为我们的中德 2+2 项目提供最优雅的课程成果展示与作业管理平台。

在此项目中，我主导了全站“无头协作知识库”与“成果展示门户”的设计与全栈重构开发。为了解决传统多人协作需要每个人安装 Git 命令行、搭建本地 Node.js 编译环境的繁琐问题，我使用 GitHub REST API 封装了浏览器内一键拉取和同步提交的逻辑，让小组成员可以在纯网页端直接像 Notion 一样编辑页面、拖拽调整块级结构、添加图片，并实时更新推送。

我狂热地喜爱编写干净、优雅的代码与设计顺滑至极的 UI 动效，坚信“好设计必须配合好代码才能发挥出最大的生命力”。平时喜欢逛 GitHub 寻找创意项目、游玩独立游戏，以及阅读跨端通信与 Web 交互相关的技术文献。

🧠 技术实力与设计亮点 / Core Tech

本项目（Team Homework Blog）是一个由我全自主独立设计和编写前端核心逻辑的作品。它具备以下技术设计亮点：

⚡ 纯前端静态无头架构

完全避免使用 React/Vue/Node.js 等外部繁重依赖，依靠浏览器原生 ES Modules 模块系统和 CSS 自定义变量构建，网页秒开，极简维护。

📝 块级 (Block) 编辑器引擎

自主手写实现了行级积木编辑器。支持 Heading 1~3、段落、代码块、列表的自由增删与即时斜杠命令快捷呼出，并且完美支持 HTML5 Drag & Drop 拖拽块排序。

🔒 全栈同步与安全拦截

通过原生 fetch 与 GitHub API 保持数据双向同步；并在客户端实施严苛的 CSP 安全拦截与 Canvas 图片自动压缩，防止 localStorage 数据溢出或 Token 被盗取。
