💡 项目概念 / Project Concept

本项目致力于针对独居老年人（或其他需要情感关怀的特殊群体），开发一款低成本、高可靠性、具备柔和感官体验的情感陪伴机器人。机器人通过主动感知环境声音和老年人的接近距离，自动调整自身的表情状态（平静、快乐、伤心、微笑、难过、兴奋），从而提供无声但温馨的“情绪陪伴”。设计理念遵循非侵入式、低感官刺激、可预测性，避免突兀的声光报警给老年人带来焦虑，为老年人构筑一个充满安全感的交互环境。

👥

缓解孤独感 / Relieve Loneliness

通过实时表情交互，为独居老人提供温馨的视觉陪伴与互动反馈。

🌿

低感官刺激 / Low Stimulation

不使用刺眼的强光或刺耳的警报音，完全通过平滑的 OLED 表情温和响应。

💓

防抖动平滑 / Anti-Flicker

设置最短表情显示延迟（630ms），避免因短暂外界噪音造成表情剧烈跳动。

🌐

IoT 远程互联 / IoT Connected

支持将交互频率、声音及距离数据上传云端，让子女能远程感知父母的活跃状态。

🏗️ 整体结构层 / System Architecture

🎤

一、听觉感知层 / Sound Input

利用 HS-S05B 声音模块捕捉老人的说话声、呼唤声或室内环境噪音。通过滤波算法滤除随机毛刺，计算出平滑的声强数据。

HS-S05B 传感器一阶低通滤波环境声强级
📏

二、距离感知层 / Distance Input

利用 HC-SR04 超声波测距传感器，实时计算老人的接近距离。采用三点中值滤波算法，消除测距异常跳变，确保数据准确稳定。

HC-SR04 传感器三点中值滤波人体接近感知
📺

三、视觉表达层 / Visual Output

将 0.96" SSD1306 OLED 屏幕作为机器人的“面部”，由 Adafruit_SSD1306 库驱动，以 42ms 的帧间隔（24FPS）平滑循环显示当前情绪的动态点阵图画。

SSD1306 屏幕Adafruit 绘图库情绪位图点阵24FPS 动画
☁️

四、IoT 数据链 / IoT Base

利用 Arduino 控制器的联网功能，将获取的距离、声音及情绪数据推送至 Web 可视化网关，方便监护人或看护中心监测老年人的日常起居活跃度。

📡 硬件设备详情 / Hardware Details

🔌

Arduino Uno R4 WiFi

微控制器 | 主控芯片

作为核心控制大脑，负责传感器数据滤波、情绪状态机判定、SSD1306 屏幕像素驱动以及数据串口/网络外发。

📏

HC-SR04 超声波测距传感器

距离传感器 | GPIO

利用声波发射与接收的时间差计算距离。测距范围 2cm - 400cm，分辨率可达 3mm。主要判定近距交互 (NEAR < 45cm) 与远距断联 (FAR > 80cm)。

🎤

HS-S05B 声音检测传感器

声强传感器 | ADC 模拟量

内置驻极体话筒与放大器，输出代表声音强度的模拟电压值。通过阈值判断判断周围是否有人大声呼唤 (LOUD > 400) 或存在轻度声响 (QUIET > 200)。

🖥️

SSD1306 0.96" OLED 点阵屏

显示模组 | I²C 协议

128x64 高对比度单色自发光点阵屏，运行在 400kHz 高速 I2C 模式，用于平滑播放 64x64 点阵的情感表情序列帧。

🧪 表情判定与状态机矩阵 / State Decision Matrix

机器人会周期性读取超声波距离与声音声强，并在每个 20ms 的循环周期内，根据下面的二维阈值状态转化矩阵决定目标情绪：

感应距离范围 (Distance) 声强状态 (Sound Level) 目标表情 (Target Mood) 交互含义与表现 (Behavioral Semantics)
近距离 < 45 cm (有人凑近看) 大声 (>400) EXCITED (兴奋) 老人正在开心地贴近大声跟它说话互动，机器人极力眨眼回应。
近距离 < 45 cm (有人凑近看) 小声/安静 HAPPY (快乐) 老人静静地陪伴在机器人跟前，机器人报以温暖的微笑与睁眼。
远距离 > 80 cm (无人接近) 大声 (>200) (远方呼唤) CALM (平静) 虽然老人离得远，但能听到声音（老人在房里走动），保持平稳待机。
远距离 > 80 cm (无人接近) 小声/安静 SAD (伤心) 无人在身旁且没有动静，超过 10 秒未活动即触发孤独/伤心动画。
中距离 45cm - 80cm (常规互动) 大声 (>200) SMILE (微笑) 老人在正常交互距离下说话，机器人露出友善的眯眼笑容。
中距离 45cm - 80cm (常规互动) 小声/安静 CALM (平静) 老人在常规距离，但没有发出声响，保持平静待机状态。

💻 Arduino 核心驱动代码 / Embedded Source Code

以下展示了 sketch_improve.ino 中最核心的传感器滤波处理与状态转移控制逻辑，体现了如何从硬件数据抽丝剥茧为老人的陪伴反馈：

// ==================== 情绪更新核心逻辑 ====================
void updateMood() {
  int raw = analogRead(SOUND_PIN);
  smoothSound = smoothSound * 0.6 + raw * 0.4; // 一阶低通滤波
  
  int dist = getDistance(); // 中值滤波获取超声波距离
  
  const int NEAR = 45, FAR = 80;
  const int LOUD = 400, QUIET = 200;
  
  bool interacting = false;
  Mood targetMood = currentMood; // 默认情绪保持不变
  
  if (dist < NEAR) {
    interacting = true;
    if (smoothSound > LOUD) targetMood = MOOD_EXCITED;
    else targetMood = MOOD_HAPPY;
  }
  else if (dist > FAR) {
    if (smoothSound > QUIET) {
      interacting = true;
      targetMood = MOOD_CALM;
    } else {
      targetMood = MOOD_SAD;
    }
  }
  else { // 中等距离
    if (smoothSound > QUIET) {
      interacting = true;
      targetMood = MOOD_SMILE;
    } else {
      targetMood = MOOD_CALM;
    }
  }
  
  if (interacting) lastActiveTime = millis(); // 记录最近活跃时间戳
  
  // 10秒超时无人理睬，机器人自动感到孤独并转为 SAD 表情
  if ((millis() - lastActiveTime > LONELY_TIMEOUT) && (smoothSound < QUIET)) {
    targetMood = MOOD_SAD;
  }
  
  // 核心切换控制：仅当前情绪显示超过 630ms 时才允许发生状态切换，防止抖动
  if (targetMood != currentMood) {
    unsigned long now = millis();
    if (now - moodChangeTime >= MIN_DISPLAY_TIME) {
      currentMood = targetMood;
      moodChangeTime = now;
      currentFrame = 0; // 重置帧，以防播放一半的表情闪烁
    }
  }
}

⭐ 项目创新点 / Design Innovations

  • 🌱
    情感抚慰导向设计

    区别于常规避障或警报设备，本机器人完全服务于陪伴，表情慢变柔和，避免电子垃圾式突兀交互。

  • 🛡️
    中值与低通双重滤波

    软件端对 HC-SR04 使用三点中值滤波去噪，对 HS-S05B 采用一阶低通平滑，数据在物理层即干净抗干扰。

  • ⏱️
    防表情跳跃切换锁

    增加了 MIN_DISPLAY_TIME 表情最小显示周期锁，使得动画哪怕在剧烈干扰下也能播满 3 遍，视觉更顺畅。

  • 📉
    极简架构与极高性价比

    仅采用百元以下的主控与基本传感器，即可达到极为高雅且高还原度的情绪算法表达，利于向社区普及。
